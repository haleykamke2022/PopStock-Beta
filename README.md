# PopStock Beta — Complete Updates

This beta package uses the complete PopStock app version with today's updates, including stock, recipes, reusable shapes, freezer tracking and reservations, orders, events, shopping, optional business and expense features, CSV expense import, and Help & Feedback.

## Files
- index.html — complete app
- manifest.webmanifest — installable web app settings
- sw.js — offline cache (updated beta version)
- icons/ — 192px, 512px and Apple touch icons

## Publishing
Upload the contents of this ZIP (not the containing folder) to the root of the beta GitHub Pages repository. Keep index.html, sw.js, and manifest.webmanifest together and the three icons in icons/.

## Important
App records are stored locally in each tester's browser under cakepop_custom_v2, not in the ZIP or GitHub. Back up before deploying updates. Do not clear browser storage or uninstall the app. Keep personal and beta installations on separate origins if they must have separate data.
